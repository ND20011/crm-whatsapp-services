Como usar los templates de links
Variables disponibles:
  • {{ '{' }}PRODUCT_ID{{ '}' }} - Se reemplaza con el ID del producto encontrado
  • {{ '{' }}SEARCH_TERM{{ '}' }} - Se reemplaza con el termino buscado por el usuario
Ejemplos de templates:
Link a producto especifico:
https://mitienda.com/producto?id={{ '{' }}PRODUCT_ID{{ '}' }}
Genera: https://mitienda.com/producto?id=12345
Link a busqueda general:
https://mitienda.com/buscar?q={{ '{' }}SEARCH_TERM{{ '}' }}
Genera: https://mitienda.com/buscar?q=celulares
Link estatico:
https://mitienda.com/productos-destacados
Siempre lleva a la misma pagina
Como funciona:
  1. Cuando la IA encuentra productos, usa el template configurado
  2. Si hay {{ '{' }}PRODUCT_ID{{ '}' }}, genera un link por cada producto
  3. Si hay {{ '{' }}SEARCH_TERM{{ '}' }}, genera un link de busqueda general
  4. El link aparece al final de la respuesta de la IA
